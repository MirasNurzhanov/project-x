# M1 — Public birthdays

Implemented: public-profile and nearby-map serializers emit calendar-derived
`age`, not `date_of_birth`. The authenticated owner's profile retains DOB for
editing. Private/minimal profiles retain their existing visibility gates.
The mobile public profile consumes `age` directly; no client DOB calculation
or legacy DOB fallback is retained on that surface.

`users.test_privacy_batch` verifies stranger serializers and the public endpoint
omit the exact date, owner compatibility, birthday boundaries and leap-day ages.
No schema migration. Older clients may display no age until updated; they are
not sent DOB for backward compatibility. No production or device run performed.
