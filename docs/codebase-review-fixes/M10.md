# M10 — Structured, privacy-conscious application logging

Status: repository implementation and local audit complete; Railway/edge collection
and deployed ASGI logging still require live verification.

Django, application module loggers and uvicorn handlers emit JSON lines to stdout:
timestamp, level, logger, event, request ID and selected numeric fields. Exceptions
retain type and source locations, not exception text, request bodies or locals.
Middleware generates a fresh request ID, returns it as `X-Request-ID`, and isolates
it across sync/async requests with ContextVar. Django's later response logs recover
the ID from the request object. Client-supplied IDs are not trusted. WebSocket
and background events do not claim HTTP request correlation.

Production push/zone/socket print statements were replaced with module events.
The audit removed raw provider exceptions, push tokens, exact coordinates,
queried place names and OSM identifiers from location/request logs, plus viewer
IDs from feed ranking logs. Classification categories and aggregate metrics remain.
Go push/moderation error logs no longer emit provider bodies or frame errors;
the push server no longer logs arbitrary URL paths. Management/diagnostic commands
may still intentionally print operator-facing output; they are not request logging.

Defence-in-depth redaction covers bearer tokens, JWTs, Expo push tokens, URL query
credentials and known sensitive mapping keys. Framework access/security records
do not serialize arbitrary paths, client addresses or rejected headers. This is
not a guarantee that arbitrary future log statements are safe: never pass raw
request data or provider payloads to a logger. Do not enable provider/HTTP debug
logging in production. The platform's separate edge/access logs are outside this
repository and require their own audit, especially for signed media URLs.

Tests verify single-line JSON, secret/exception redaction, framework-path privacy,
request-ID cleanup on errors and isolation across 20 concurrent async requests.
Region classification assertions now require location-identifying fields to be
absent. Go suites pass with race detection. See [OPERATIONS_VALIDATION.md](OPERATIONS_VALIDATION.md).
