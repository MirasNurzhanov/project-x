# M13 — Unicode moderation normalization

Implemented: NFKC/case folding retains Unicode letters, numbers and combining
marks. Latin accents are folded for existing English evasion rules, while
Cyrillic й/ё and Arabic/Indic marks are preserved. Invisible separators are
removed; punctuation still separates words; existing repeated-letter and joined
forms remain part of the moderation pipeline.

users.test_privacy_batch covers Cyrillic, Kazakh, Japanese/Chinese, Arabic and
Indic text, meaningful marks, invisible characters and Latin accents. The
existing moderation/user/proximity suites pass (686 tests before adding these
five new batch regressions; the five dedicated tests also pass).

This is NOT multilingual coverage for the English policy word lists. Non-Latin
text now reaches the pipeline intact, but additional language-specific rules or
validated classifiers are still required for broad multilingual enforcement.
No claim that all harmful non-English text will now be detected. No deployment.
