# M7 — Location accuracy

Implemented: the foreground location hook stores accuracy alongside the accepted
fix, rejecting stale callbacks together with their accuracy. The map poll must
receive that reference and forwards it through the normal privacy-gated reporter.
Valid finite nonnegative accuracy, including zero, is transmitted; explicit
unknown values become null. Omitted accuracy remains omitted.

The server only writes location_accuracy_m when accuracy is supplied. Omission
preserves the existing value; explicit null/-1 clears it. This intentionally
retains compatibility with older clients that did not transmit accuracy.

Backend regression: users.test_privacy_batch. Mobile regressions cover accepted
and stale fixes, unknown accuracy, foreground forwarding and privacy gates:
locationAccuracy, mapLocationLifecycle and mapGhostPrivacy (28 tests passed).
Full mobile suite: 826 tests passed; TypeScript passes. No schema migration.
